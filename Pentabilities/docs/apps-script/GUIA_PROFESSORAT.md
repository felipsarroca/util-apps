# Guia ràpida per al professorat

## Primer accés

1. Entra a la URL de l'aplicació amb el correu de l'escola.
2. Si és el primer accés, Google pot demanar autoritzar permisos.
3. L'app crearà automàticament el Google Sheets de dades i hi carregarà alumnat, professorat i comportaments.

## Crear un cicle

1. Prem `Nou cicle`.
2. Escriu el nom del cicle.
3. Tria la classe.
4. Desa el cicle.

## Crear una sessió

1. Prem `Nova sessió`.
2. Tria el cicle.
3. Escriu el nom de la sessió.
4. Selecciona entre 3 i 6 comportaments.
5. Selecciona, si vols, alumnes per a heteroavaluació.
6. Desa la sessió com a oberta.
7. Projecta el codi de sis xifres a l'aula.

## Avaluar

- L'alumnat entra amb el codi i fa autoavaluació i coavaluació.
- El professor pot entrar a `Heteroavaluar` i valorar alguns alumnes.
- Les dades queden registrades com a files independents a `Avaluacions`.

## Dashboard

El botó `Dashboard` mostra un resum bàsic amb:

- alumnat que ha respost,
- alumnat pendent,
- mitjana global,
- mitjana per comportament.
