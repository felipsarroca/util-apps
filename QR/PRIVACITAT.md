# Política de privacitat

Lector QR processa les imatges i els codis QR només al dispositiu. No guarda cap historial, no envia el contingut dels QR a cap servidor i no incorpora anuncis ni analítica.

L'app demana accés a la càmera per llegir codis. Si tries una fotografia, el selector d'Android dona accés únicament a la imatge escollida. El permís d'Internet serveix exclusivament per consultar, com a màxim un cop cada set dies o quan ho demanis, si hi ha una versió estable nova a GitHub Releases. GitHub pot rebre les dades tècniques habituals d'una petició HTTPS, com l'adreça IP. Les accions d'obrir, compartir o copiar un resultat només s'executen quan les tries.

Projecte: https://github.com/felipsarroca/lector-qr-android
