# La teva veu: guió de la prova pilot

**Objectiu:** comprovar, amb alumnat real i **dades fictícies**, que les preguntes s'entenen, quant es triga i on s'encalla l'alumnat. No es desa cap resposta real: tothom fa servir els comptes de prova de la demostració.

## 1. Organització

| | |
| --- | --- |
| **Qui** | 3 o 4 alumnes de cada cicle: 3r-4t, 5è-6è i ESO. Barregeu nivells de lectura i alumnat nouvingut o amb NESE |
| **Durada** | 10-15 minuts per alumne |
| **On** | Un racó tranquil, amb l'ordinador o la tauleta que farà servir l'alumnat a l'aula |
| **Qui observa** | Un docent que no sigui el que l'alumne valorarà |
| **Material** | L'app oberta, aquest full i un cronòmetre |

Adreça: https://felipsarroca.github.io/util-apps/LaTevaVeu/#/et-veig

Comptes de prova, segons l'etapa:
- **Alumne de 3r**: cicle mitjà.
- **Alumna de 5è**: cicle superior.
- **Alumne de 2n d'ESO**: ESO.

> Abans de cada alumne, obriu l'app en una finestra privada perquè comenci de zero.

## 2. Què dir a l'alumne (1 minut)

> Estem provant una aplicació nova i ens ajudes a millorar-la. **No t'avaluem a tu: avaluem l'aplicació.** Les respostes no són de veritat i no les llegirà ningú. Pensa en veu alta: digues el que penses mentre la fas servir, sobretot si alguna cosa no s'entén.

## 5. Tres preguntes en acabar

1. «Hi ha alguna pregunta que no sabies què volia dir?»
2. «Creus que el mestre sabrà què has dit tu?» *(comprova si ha entès la confidencialitat)*
