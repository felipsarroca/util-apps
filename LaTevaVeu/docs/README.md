# La teva veu: documents de treball

Material per a les fases 3 (validació pedagògica) i 4 (validació de privacitat) del [pla mestre](../La_teva_veu_pla_mestre_v2.md).

| Document | Per a qui | Per a què |
| --- | --- | --- |
| [01 Dossier de privacitat](01_Dossier_de_privacitat.md) | Direcció i DPD | Revisar i validar el tractament de dades abans de recollir dades reals |
| [02 Textos informatius](02_Textos_informatius.md) | Famílies, alumnat i claustre | Informar abans de la primera recollida |
| [03 Google Workspace](03_Google_Workspace.md) | Administració de Google | Autoritzar l'inici de sessió, també per a l'alumnat menor d'edat |
| [04 Presentació al claustre](04_Presentacio_claustre.md) | Equip Directiu | Presentar «Et veig» al claustre |
| [05 Revisió de preguntes](05_Revisio_preguntes.md) ([CSV](05_Revisio_preguntes.csv)) | Claustre | Revisar les afirmacions de cada etapa |
| [06 Guió de la prova pilot](06_Guio_prova_pilot.md) | Docents que observen | Provar l'app amb alumnat i dades fictícies |
| [07 Inventari d'assignacions](07_Inventari_assignacions.md) ([plantilla CSV](07_Plantilla_assignacions.csv)) | Coordinació i secretaria | Recollir qui fa cada matèria a cada grup i importar-ho |

Els documents 05 i la plantilla 07 es generen a partir de l'app amb `npm run docs`: torneu-los a generar si es canvien les preguntes o les matèries.
